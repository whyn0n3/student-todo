## Как описать найденную ошибку

Для каждой ошибки создать отдельную запись:

- Название: кратко описать проблему.
- Окружение: ОС, версия Python и проверенный коммит.
- Действия: точная последовательность команд и введённых значений.
- Ожидалось: нужное поведение.
- Получилось: фактическое поведение и полный текст ошибки, если он есть.
- Повторная проверка: результат после исправления.
