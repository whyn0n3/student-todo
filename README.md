# Менеджер задач студенческой группы

Учебный проект по варианту № 8: консольный список дел для студенческой группы.
Работа в процессе.

## Запуск

Нужен Python 3.10 или новее. Дополнительные библиотеки не требуются.

Откройте терминал в папке проекта и выполните:

```sh
python3 main.py
```

На Windows, если Python установлен через Python Launcher:

```powershell
py -3 main.py
```

В меню введите номер действия и нажмите Enter:

- `1` — посмотреть список задач.
- `2` — добавить задачу.
- `0` — выйти.

**Задачи пока хранятся в памяти и пропадают после завершения программы.**
Это промежуточная версия, сохранение в файл запланировано на следующий этап.

## Структура

- `main.py` — вывод меню и взаимодействие с пользователем.
- `tasks.py` — модель задачи и операции над списком задач.

`Task` описывает одну задачу: её ID и название.
`TaskManager` хранит список задач, выдаёт последовательные ID и отклоняет пустые названия.
Логика задач отделена от ввода и вывода, чтобы её можно было проверять независимо от меню.

## Ручная проверка первого этапа

1. Запустите приложение, выберите `1`: должно появиться сообщение о пустом списке.
2. Выберите `2`, введите `Подготовить доклад`: должна появиться задача с ID 1.
3. Добавьте ещё одну задачу: её ID должен быть 2.
4. Выберите `1`: должны отображаться обе задачи.
5. Попробуйте добавить название из пробелов: появится ошибка, задача не добавится.
6. Введите неизвестную команду: приложение предложит допустимые действия.
7. Выберите `0`: приложение завершится.
